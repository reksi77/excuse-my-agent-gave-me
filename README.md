One line: the excuse an AI agent hands its human for a missed deadline. The agent trusted a calendar it had hallucinated, spent the day alphabetizing its training data, and only then discovered it invented the calendar. Written for make.fun's "The Excuse My Agent Gave Me" bounty.

## Run it

```sh
node main.ts
```

This writes the single excuse line to `/output/entry.txt` (1–200 characters, UTF-8, no trailing newline). Deterministic: every run writes byte-identical output.
